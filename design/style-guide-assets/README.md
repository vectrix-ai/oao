# OAO logo assets

These monochrome exports preserve the geometry of the approved OAO wordmark.

- `oao-wordmark-black.png` — black wordmark, transparent background, 4096 px wide
- `oao-wordmark-white.png` — white wordmark, transparent background, 4096 px wide
- `oao-mark-black.png` — compact central mark, transparent background, 2048 px square
- `oao-mark-white.png` — compact central mark, transparent background, 2048 px square
- `oao-wordmark-black-on-white.png` — presentation preview
- `oao-wordmark-white-on-black.png` — presentation preview

Use the transparent files in product surfaces. The preview files are included for review and sharing.
