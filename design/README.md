# OAO design references

These standalone HTML artifacts are used to review and iterate on the product
design before approved decisions are implemented in the console.

- [`design.html`](./design.html) is the current interactive component-system
  prototype.
- [`style-guide.html`](./style-guide.html) documents the OAO identity,
  typography, palette, logo usage, and foundational tokens.
- [`style-guide-assets/`](./style-guide-assets/) contains the local logo assets
  used by both documents.

The files in this directory are design references. They are not bundled into
the production console.
