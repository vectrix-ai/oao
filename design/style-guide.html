01 / CLEAR SPACE

Let it breathe

Keep clear space equal to at least half the height of one “o” around every side of the wordmark.

02 / MINIMUM SIZE

Stay legible

Use the full wordmark at 72 px wide or larger. Below that, switch to the compact center mark at 20 px or larger.

03 / INTEGRITY

Keep it exact

Do not stretch, outline, recolor individual letters, add effects, or recreate the mark with a font.

02 · Color

Verdant signal

The primary scale is anchored on the selected UI Colors seed #6ebc91. Green signals live, healthy and approved states; near-black neutrals keep complex debugging views calm and readable.

Action

Use green 700 for primary buttons and important links on light surfaces. Hover at 800.

Selection

Use green 100 for selected rows, filters and gentle active states with 800 text.

Live signal

Use green 500 for focus rings, live indicators and charts—not small white text.

05 · Foundations

Implementation tokens

Use semantic tokens in application code. Components should reference roles such as --color-action, never a raw shade, so light and dark themes remain coherent. 

:root {
  --color-action: #3d7c5c;
  --color-action-hover: #326349;
  --color-focus: #6ebc91;
  --color-canvas: #f7f9f8;
  --color-surface: #ffffff;
  --color-text: #141a17;
  --color-muted: #52605a;
  --color-border: #d9deda;

  --radius-control: 8px;
  --radius-panel: 12px;
  --space-unit: 4px;
}
Accessibility rule The seed green #6ebc91 is a signal color. Pair it with near-black text. For text links and primary buttons on light surfaces, use green 700 or 800. Never rely on color alone for status: pair it with a label, icon or shape.

Shape & spacing Build layouts on a 4 px spacing unit. Use 8 px corners for controls, 12 px for data panels and up to 20 px for editorial brand cards. Prefer borders over heavy shadows in the application console.
