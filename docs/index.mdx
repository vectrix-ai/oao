OAO is an open, self-hostable managed-agent platform built with TypeScript,
Flue, and PostgreSQL. It gives teams one place to define versioned agents,
start durable sessions, inspect their public transcripts and timing, and safely
hand caller-owned tool work back to an application.

The guided local setup checks your machine before making changes, starts the
stack, connects OpenRouter, OpenAI, Anthropic, or xAI, creates a starter agent, and runs its first
session. Development authentication stays local; Daytona is optional until you
enable sandbox tools.

## What you can inspect

The React console at `http://127.0.0.1:8080` displays managed agents and their
immutable versions, the project's approved model presets, sessions and runs, the
diagnostic transcript, caller tool and approval work, public errors, timing
entries, and observed token/cost metadata.
It receives live changes from the same durable PostgreSQL event stream exposed
to client applications.

<Note>
  Authorized session transcripts expose model reasoning and sandbox tool
  input/output for debugging. Credentials, authorization headers, reasoning
  signatures, and unrestricted SSE/log payloads remain excluded.
</Note>

## Choose a path

1. Follow the [guided quickstart](/getting-started/quickstart) to verify your
   machine and run a first session.
2. Use [Create an agent](/agents/create-agent) to publish a usable definition.
3. Follow [Connect a codebase](/integrations/codebase) for a complete Node.js
   integration, including real-time updates and repository file access.

If you are implementing a different client, use the [HTTP API
reference](/reference/http-api) and [event stream contract](/reference/events).
